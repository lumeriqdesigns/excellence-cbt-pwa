=====================

2. On GitHub: delete ALL files in the repo (or empty the repo)
3. Upload everything from this folder to the REPO ROOT

   cd MeritScholars_GitHub

   git add .
   git commit -m "Full MeritScholars replace"
   git branch -M main
   git remote add origin https://github.com/lumeriqdesigns/excellence-cbt-pwa.git
   git push -u origin main --force
